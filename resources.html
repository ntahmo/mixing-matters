Every model construction demonstrated in the explorer has a corresponding Python implementation. R examples are provided for independent replication.

Run locally

python tests/test_mixing.py
python code/mixing.py
Rscript code/mixing.R

The Python example uses only the standard library. R examples use base R. The two-axis implementation uses a symmetric iterative scaling algorithm and raises an error if it cannot achieve the requested numerical tolerance.

Numerical validation is not epidemiological validation

Passing reciprocity and normalization tests confirms specific mathematical properties. It does not show that the selected mixing structure matches actual partnerships, correctly identifies causal pathways, or predicts incidence. That requires empirical calibration, transparent assumptions, and sensitivity analyses.

Repository status: illustrative teaching implementation. Do not substitute these examples for project-specific model calibration or external scientific review.
